## About Solara

Solara is a Windows desktop Roblox script executor focused on keeping Lua execution straightforward. Its compact interface brings together script launching, a built-in collection of scripts, and the essential controls needed for a simple local workflow.

The application is built around local execution, continuing updates, and a library containing more than 500 scripts for common Roblox-related uses. Windows compatibility and a key-free setup are combined with utility functions intended to make script access more convenient.

## Frequently Asked Questions

**Does Solara run as a desktop application?**  
Yes. Solara is provided as a Windows desktop tool with local script handling and built-in management features.

**What happens when Roblox receives an update?**  
Its automatic update system is intended to help the application track newer releases. However, compatibility may change over time.

**What does Solara offer beyond a basic script loader?**  
Alongside launching scripts, Solara provides a script hub, SQLite-backed queue persistence, batch execution, and debugging tools.

**Can using an executor create account-related risk?**  
Third-party tools may carry account or platform risks when used with Roblox. Check Roblox's terms and consider the consequences before executing scripts.

**What information is saved on the computer?**  
The queue is stored through SQLite. Associated settings and hub information may also remain locally available for future sessions.
